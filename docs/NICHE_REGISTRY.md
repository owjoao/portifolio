## 🔗 Convenções de Nomenclatura

### Pastas de Nicho
- **Formato**: `kebab-case` (ex: `energia-solar`, `clinica-oftalmo`)
- **Local**: `niches/{nicho}/`
- **Admin (quando aplicável)**: `niches/{nicho}/admin/`

### Arquivos Principais
- **Landing Page**: `niches/{nicho}/index.html`
- **Painel CRM**: `niches/{nicho}/admin/index.html`
- **Preview Asset**: `portal/assets/previews/{nicho}.png`
- **Token de Design**: `shared/design-tokens/{nicho}.json`
- **Template WhatsApp**: `shared/templates/whatsapp/{nicho}.txt`

### URLs Públicas (Após Deploy)
- **Portal**: `https://seu-dominio.vercel.app/`
- **Nicho**: `https://seu-dominio.vercel.app/{nicho}/`
- **CRM**: `https://seu-dominio.vercel.app/crm-vendas/` ou `/crm-servicos/`

## 🛠️ Como Adicionar Novo Nicho

1. **Criar Tokens de Design**
   ```bash
   cp shared/design-tokens/modelo.json shared/design-tokens/{novo-nicho}.json
   # Editar cores, fontes, copy específico
   ```

2. **Atualizar Catálogo**
   ```bash
   # Adicionar entrada em projects_catalog.json
   # Adicionar config em niche_configs.py ou remaining_niches_data.py
   ```

3. **Criar Landing Page**
   ```bash
   # Copiar template base
   cp shared/templates/base.html.jex shared/templates/{novo-nicho}.html.j2
   # Personalizar com componentes específicos
   ```

4. **Build e Testar**
   ```bash
   cd scripts
   python build_niche_db.py
   python build_clean_light_portal.py
   # Verificar em niches/{novo-nicho}/index.html
   ```

5. **Commit e Deploy**
   ```bash
   git add .
   git commit -m "feat: adicionar nicho {novo-nicho}"
   git push origin main
   # Vercel deploy automático
   ```
